Kebijakan Privasi

Berlaku sejak 29 Oktober 2026.

CatatUang menyimpan semua data (pengeluaran, pemasukan, transfer antar-dompet, anggaran, target tabungan, dan foto struk) hanya di perangkatmu, di database lokal. Data tidak dikirim ke server kami atau pihak ketiga, dan tidak ada akun pengguna.

Izin Akses Notifikasi (Notification Listener) dipakai hanya untuk membaca notifikasi pembayaran dari aplikasi bank dan e-wallet yang masuk daftar putih. Teks notifikasi mentah tidak disimpan permanen setelah diproses; digunakan fingerprint untuk mencegah duplikasi.

Aplikasi dapat mengecek rilis terbaru di GitHub (api.github.com) untuk menampilkan pembaruan. Koneksi internet hanya dipakai untuk itu dan unduhan APK atas tindakan pengguna.

Foto struk dibaca langsung di perangkat dengan Tesseract.js dan dapat disimpan sebagai berkas terpisah.

Izin kamera/galeri dipakai saat memilih atau memotret foto struk. Izin biometrik/PIN hanya untuk mengunci aplikasi lokal.

Menghapus data atau mencopot aplikasi menghapus semua datamu. Buat cadangan berkala lewat menu Atur - Cadangan dan Pemulihan.

Pertanyaan: hubungi pemilik repositori Exsors-Code/catat-uang-apk lewat GitHub.

Privacy Policy

CatatUang stores all data only on your device. Notification Listener permission is used strictly for whitelisted bank/e-wallet payment notifications. The app may check GitHub releases for updates. No data uploaded.
